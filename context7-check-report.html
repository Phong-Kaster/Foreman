3 · What to tighten3 · Những gì nên siết thêm

Improvement 1 · query the symbol that failedCải thiện 1 · truy vấn đúng ký hiệu bị lỗi

The engine asked about what the task does, not about what broke. Asked directly ("SimpleExoPlayer migration to ExoPlayer.Builder"), Context7 returns the migration itself; asked about the task, it returned the fix only because one page also builds a player. One sentence in POLICIES.md and the skill — "name the failing symbol and what replaced it, not the task" — closes the gap. Applied on PR #5, and pinned by a test.

Engine hỏi về việc task làm, chứ không hỏi về thứ bị hỏng. Hỏi thẳng ("SimpleExoPlayer migration to ExoPlayer.Builder") thì Context7 trả về đúng hướng dẫn chuyển đổi; hỏi theo task thì nó chỉ ra cách sửa vì một trang tình cờ có đoạn dựng player. Thêm một câu vào POLICIES.md và skill ("hỏi đúng ký hiệu bị lỗi và thứ thay thế nó, không hỏi về task") là đủ. Đã áp dụng trên PR #5, kèm test ghim.

Improvement 2 · one wasted turn, unrelated to Context7Cải thiện 2 · một lượt bị phí, không liên quan tới Context7

The engine first tried to write the Brief with cat > … <<EOF through Bash; the Collaborative permissions correctly denied it, and it switched to the Write tool. The denial is the permission model working, not a Context7 issue, but it cost a turn.

Engine lần đầu ghi Brief bằng cat > … <<EOF qua Bash; bộ quyền Hợp tác từ chối đúng, và nó chuyển sang tool Write. Việc bị từ chối là bộ quyền đang làm đúng việc, không phải lỗi của Context7, nhưng nó tốn một lượt.

4 · What this check does not prove4 · Những gì lần kiểm tra này chưa chứng minh

  • That the prepared retry compiles: the scratch repository has no Gradle project, so the build that would decide was not run.
  • That a Worker uses the excerpt well: no Worker was dispatched.
  • That the engine reaches for Context7 unprompted inside a full run: the prompt named the retry step. A real run in a consumer repository is the next evidence.
  • Autonomous mode, where Bash is allowed wholesale and the grant is not needed.
  • A library Context7 does not index, or a rate limit hit.
  • Lần thử lại đã chuẩn bị có compile được không: repo nháp không có project Gradle, nên chưa chạy build để phân định.
  • Worker có dùng tốt đoạn tài liệu không: chưa giao việc cho Worker nào.
  • Engine có tự tìm tới Context7 trong một run đầy đủ không: prompt đã chỉ đúng bước retry. Run thật ở repo consumer là bằng chứng tiếp theo.
  • Chế độ Tự động, nơi Bash được phép toàn bộ và không cần cấp quyền riêng.
  • Thư viện mà Context7 không có, hoặc khi chạm giới hạn số lần gọi.
